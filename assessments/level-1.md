# Level 1 — Bash Fundamentals

Try these tasks without copying a completed solution. Use Ubuntu/WSL.

1. Create `hello.sh` that prints a greeting, current user, date, and current directory.
2. Store your name and a learning topic in variables and print them.
3. Ask for a name using `read -r`; show a useful error if it is empty.
4. Ask for a path and report whether it is a file, directory, or missing.
5. Make a script executable and run it using `./script.sh`.

## Self-check (10 points)

- [ ] Script runs without syntax errors (2)
- [ ] Variables are quoted properly (2)
- [ ] Input is validated (2)
- [ ] Correct file permissions are used (2)
- [ ] You can explain every command (2)

**Pass target:** 8/10. If you miss a task, review the relevant example and try again.
