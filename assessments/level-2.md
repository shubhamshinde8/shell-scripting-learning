# Level 2 — Conditions, Loops and Files

1. Write a menu using `case` that offers three harmless choices and an Exit option.
2. Use a loop to print numbers 1 through 10.
3. Write a function that checks whether a supplied path is a file or directory.
4. Create a sample log file yourself and count lines containing `ERROR`.
5. Handle missing input and missing files with clear messages and non-zero exit statuses.

## Self-check (10 points)

- [ ] Correct condition and loop syntax (2)
- [ ] Menu exits when requested (2)
- [ ] Function uses arguments correctly (2)
- [ ] File and log handling works with spaces in paths (2)
- [ ] Invalid input is handled safely (2)
